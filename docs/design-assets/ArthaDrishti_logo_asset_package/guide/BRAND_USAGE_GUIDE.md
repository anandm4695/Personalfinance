# ArthaDrishti Brand Usage Guide

This package is rebuilt from the supplied ArthaDrishti reference artwork. The original black-background file is included in `source/ArthaDrishti.png`, and the white-background production master is included in `source/ArthaDrishti-white.png`. The reference-faithful SVGs preserve the submitted artwork as an embedded image so the supplied visual treatment remains unchanged.

## File Selection
- Use `png/lockups/arthadrishti-stacked.png` when the exact supplied composition is required.
- Use `png/lockups/arthadrishti-horizontal.png` for wide software headers.
- Use `svg/` when an SVG container is required by the software stack.
- Use `png/icon/` for transparent emblem assets.
- Use `png/app-icon/` for dark launcher tiles.
- Use `favicon/` for browser and PWA setup.
- Use `monochrome/` where color reproduction is unavailable.

## Visual Direction
The approved visual language is a clear white-background presentation of the luminous navy, green, and gold wealth-growth emblem with a tree, rising arrow, rupee coin, coin stack, and the tagline “Wealth Today. Vision Tomorrow.”

## Usage
Keep the complete lockup on white or very light surfaces for the clearest presentation. Keep clear space around the emblem equal to at least the coin diameter. Do not stretch, rotate, recolor, or add additional effects.
